# Security policy

Report suspected vulnerabilities in either npm package privately through GitHub. The maintainer can discuss reproduction steps, affected versions, a fix and coordinated disclosure with you in the advisory. [Report a vulnerability](https://github.com/lpshanley/oidc-start/security/advisories/new)

Include the affected package and version, Node and provider versions, the expected and observed behavior, and a minimal reproduction using test accounts. Replace tokens, cookies, client secrets, signing keys and personal data with synthetic values. Use public issues for ordinary bugs and integration questions.

For deployment assumptions, key rotation and the division of responsibility between the library and the host, see the [production guide](docs/production.md).
